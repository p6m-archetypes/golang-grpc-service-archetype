# {{ project_title }}

Go gRPC service generated by `golang-grpc-service-archetype`.

## Getting started

### Generate protobuf code

```bash
make proto
```

This runs `buf generate` and produces Go code under `gen/`.

### Build

```bash
make build
```

### Test

```bash
make test
```

### Run

```bash
make run
```

gRPC on port `{{ service_port }}`, HTTP management on `{{ management_port }}`.

## Proto definition

The service definition lives at `proto/{{ prefix_name }}_{{ suffix_name }}/{{ prefix_name }}_{{ suffix_name }}.proto`.

After running `make proto`, register the generated server in `cmd/server/main.go` and implement the interface in `internal/service/service.go`.
